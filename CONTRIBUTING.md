# Contributing

This repository does not contain Maptridge's source code and does not accept pull requests.

You can still help a lot: [report bugs](https://github.com/JanitorHead/maptridge-feedback/issues/new?template=1-bug_report.yml), [suggest ideas](https://github.com/JanitorHead/maptridge-feedback/issues/new?template=2-feature_request.yml), and vote with 👍 on the issues you care about.
