# Maptridge feedback

Bug reports and suggestions for **[Maptridge](https://maptridge.pages.dev)**: game maps you fill in yourself as you play, starting with the [Metroid (NES) map](https://maptridge.pages.dev/metroid-nes/).

Maptridge is closed source. This repository holds no code; it is only where players report problems and ask for things.

## Report something

- **[Report a bug](https://github.com/JanitorHead/maptridge-feedback/issues/new?template=1-bug_report.yml)**: something broken, a room or door that does not match the game, a wrong item.
- **[Suggest an idea](https://github.com/JanitorHead/maptridge-feedback/issues/new?template=2-feature_request.yml)**: a feature, a change, or the next game you would like mapped.
- **[Search existing issues](https://github.com/JanitorHead/maptridge-feedback/issues?q=is%3Aissue)** first: someone may have reported it already. A 👍 on an issue counts as a vote.

The **Report a bug** link inside Maptridge fills in your version for you.

## Good to know

- Issues are public. Do not post personal data. A saved map file only contains your map and passwords, but check before you attach it.
- Security problems go through [private vulnerability reporting](https://github.com/JanitorHead/maptridge-feedback/security/advisories/new), not public issues. See [SECURITY.md](SECURITY.md).
- Pull requests are not accepted, because there is no code here to change.

Maptridge is an unofficial fan project, not affiliated with Nintendo.
